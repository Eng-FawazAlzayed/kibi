KIBI privacy policy

Last updated: 4 November 2026

KIBI is a personal app used only by its owner. This page explains what it does with Google data.

What KIBI accesses

  • Google Calendar (calendar.events): to add events the owner asks for and to read the owner's schedule back to them.
  • Gmail, read-only (gmail.readonly): to search the owner's inbox when asked and to summarize new mail. KIBI never sends, deletes or changes mail.

Where the data goes

  • The phone connects directly to Google. KIBI's server doesn't hold the owner's Google sign-in, and by default new mail notifications are built on the phone.
  • If the owner asks about mail in chat and has set up their own server, the question and the matching emails' details and preview text are sent to an AI model (Anthropic's Claude) through that server to find and write the answer. This doesn't depend on the "smarter summaries" setting, and these emails aren't filtered, so a preview could contain a one-time code.
  • If the owner turns on "smarter summaries", the text of new mail worth a notification is sent to Claude through the same server to write a short summary. Mail recognized as a one-time code or a promotion isn't sent this way.
  • What the owner says when adding a calendar event may also be sent to Claude through that server, so KIBI can understand the request.
  • The server is designed to pass this text to Claude without storing it. Anthropic handles it under its own terms.
  • KIBI doesn't sell Google data or use it for advertising, and doesn't transfer it to anyone except as described on this page.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Disconnect in KIBI's Settings, or remove KIBI at myaccount.google.com/connections.
